# MedBud

Internal assistant for MediAssist Health Network: staff ask questions in plain English and get cited
answers from the documents their role is allowed to see, plus analytics over the claims and
maintenance databases for roles with reporting duties. Access control is enforced inside the vector
store query, not in the UI.

Design: see `DESIGN.md`. Setup, demo accounts, architecture and the RBAC test log will be filled in
as the components land.
